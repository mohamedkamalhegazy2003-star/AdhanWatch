# ⌚ الأذان – Samsung Galaxy Watch 4 Classic (Wear OS)

تطبيق أذان لساعة Wear OS: مواقيت صلاة مدن مصر (طريقة الهيئة المصرية العامة للمساحة، فجر 19.5° / عشاء 17.5°، العصر شافعي)، اختيار صوت المؤذن، وتشغيل الأذان تلقائياً في موعد كل صلاة (يعمل بدون إنترنت).

## 1) إضافة أصوات المؤذنين
ضع ملفات الصوت (mp3 / ogg / m4a / wav) في:
`app/src/main/assets/adhan/`
اسم الملف = اسم المؤذن الظاهر في التطبيق (الشرطة السفلية تتحول لمسافة)، مثال: `مشاري_العفاسي.mp3`
> استخدم ملفات مسموح لك باستخدامها. يفضّل ملف واحد قصير (3–4 دقائق) لكل مؤذن لتوفير مساحة الساعة.
بدون ملفات صوت، التطبيق يشتغل بصوت المنبه الافتراضي.

## 2) البناء على GitHub
1. أنشئ مستودع جديد على GitHub وارفع كل محتويات هذا المجلد (بما فيها مجلد `.github`).
2. افتح تبويب **Actions** وانتظر انتهاء **Build APK** (أو شغّله يدوياً: Run workflow).
3. ادخل على آخر تشغيل ← **Artifacts** ← حمّل `AdhanWatch-APK` وفك الضغط لتحصل على `app-debug.apk`.

## 3) تثبيت التطبيق على الساعة (ADB لاسلكي)
1. في الساعة: الإعدادات ← حول الساعة ← معلومات البرنامج ← اضغط **إصدار البرنامج** 7 مرات لتفعيل وضع المطور.
2. الإعدادات ← خيارات المطور ← فعّل **ADB debugging** و **Debug over Wi-Fi** (وصّل الساعة بنفس شبكة الواي فاي مع الكمبيوتر).
3. من الكمبيوتر (يلزم تثبيت platform-tools):
```
adb pair IP:PAIR_PORT      # ثم أدخل كود الاقتران الظاهر في الساعة
adb connect IP:PORT
adb install app-debug.apk
```

## 4) إعدادات مهمة على الساعة
- اسمح بالإشعارات عند أول فتح.
- الإعدادات ← التطبيقات ← الأذان ← البطارية ← **بدون قيود (Unrestricted)** حتى لا يوقفه النظام.
- ارفع صوت الساعة (الأذان يشتغل بقناة المنبه).

## ملاحظات
- المنبه يُجدول بـ `setAlarmClock` فيشتغل بدقة حتى في وضع توفير الطاقة، ويُعاد جدولته بعد إعادة التشغيل أو تغيير التوقيت.
- التوقيت الصيفي في مصر محسوب تلقائياً (Africa/Cairo).
- قارن المواقيت أول مرة بتقويم الهيئة المصرية للمساحة؛ الفرق عادةً دقيقة أو دقيقتين.
